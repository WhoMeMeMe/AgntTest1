# Skill: script-writer

How to write the voiceover for this channel. Start with the **words**, not the visuals. Tensaikun: if the script is bad, no visual can save it; a good script usually turns into a good video. Read the script out loud and cut anything that sounds like a textbook.

This skill sets **our** script DNA (ZacD-formula Shorts). Do not copy Tensaikun's tutorial script or any Zack D. Films narration.

---

## 1. Hard limits

| Parameter | Value |
|---|---|
| Language | English |
| Length | **75–95 words** (DNA practical target; researched top-video median was ~80) |
| Duration | ~28–35 s at **150–160 wpm** (estimate: words ÷ 2.5 ≈ seconds at 150 wpm) |
| Narrator | One calm male voice, third person or "you" |
| Ideas | **One** mechanism or question per video |
| CTA | **None.** No "subscribe," "follow," "like," "link in bio" |
| Safety | Optional one warning if the topic is dangerous |

If a draft is under 70 or over 100 words, revise before shot-planning. If estimated duration exceeds 40 s, cut.

## 2. Hook (0–3 seconds = 1–2 clauses)

Pick one pattern (from the ZacD DNA — **[ours]** as the channel brief):

- **A.** If you [relatable situation], most people think [myth], but…
- **B.** When you [ordinary action], [the body / the object] actually [visual step 1].
- **C.** [Strange action in medias res, no intro.]
- **D.** Have you ever wondered why [everyday object]…?

Tensaikun's useful addition, applied here: the hook should already be the **proof or the strongest moment**, not a brand intro and not a slow "city waking up." If the most interesting image happens at 0:20, **move that moment to 0:00** (in the script and later in the edit list).

Do not open with "Hey guys," "in this video," or a channel name.

## 3. Story arc (timestamps are a guide)

| Beat | Time | Job |
|---|---|---|
| 1. Hook | 0–3 s | Pattern A–D, already visual |
| 2. Myth / setup | 3–7 s | "People think X." Sometimes fused with the hook |
| 3. Dive | ~8–20 s | We enter the mechanism. Cause and effect, in order |
| 4. Twist / escalation | ~20–28 s | A complication, a scale change, or "and then it gets worse/stranger" |
| 5. Payoff | ~28–33 s | A visual resolution the viewer can *see*. The last sentence lands on that image |
| 6. CTA | — | **Omit** |

## 4. Line-level craft

- Short sentences. Concrete verbs. Prefer things a camera can show.
- Numbers beat adjectives ("two millimeters," "three layers," "a 24-volt pulse") — same spirit as Tensaikun's "style in numbers."
- No textbook throat-clearing ("It is important to note that…").
- No stacked questions. One hook question is enough, and only if you chose pattern D.
- Fiction must be labeled in the title/description later: `(fiction)`.

## 5. Optional "camera sees" lines (from Tensaikun)

For more control, under every paragraph or beat, add **one line** describing what the camera sees. Example *shape* (do not reuse this topic):

```
VO: When the seal breaks, the air rushes in.
Camera sees: macro of a rubber gasket lifting; dust streaks toward the gap; slow push-in.
```

Default for finished Shorts: use these lines. For a 20-second style test, a single-block prompt is allowed (his "least work" mode).

## 6. Deliverable format

Always output:

```
TITLE: How [concrete mechanism] Works [one emoji]
WORD COUNT: nn
EST. DURATION: nn s at 155 wpm
HOOK TYPE: A/B/C/D
STRONGEST MOMENT (must play at 0:00 if it is not already there): …

SCRIPT
[full VO]

BEATS
[for each beat: time · VO · camera sees]
```

Emoji: one at the end of the title, Title Case, same string will be used on YouTube Shorts and IG Reels. Typical DNA patterns: How X Works / Why X / What If X / Could X? / How To X.
