# known-mistakes.md

Standing rules learned from reviews. Read this at the start of every video session. When a note repeats, add a row **and** patch the relevant skill file.

Tensaikun kept a list like this inside the skill (he described "rounds of rules" and examples such as trees turning with the camera, walking through props, labels covering each other). **[ours]** We keep the list in this file so the lesson log stays readable. Do not copy his film-specific rules as if they were ours; write rules that match *our* Shorts / Higgsfield mistakes.

| ID | Date added | Problem | Rule (short) | Skill updated |
|---|---|---|---|---|
| KM-001 | 2026-11-11 | Text baked into generated frames | Never ask the image/video model to draw captions, titles, logos, or watermarks | style-guide, shot-planner |
| KM-002 | 2026-11-11 | Hook buried mid-video | Move the strongest moment to 0:00–0:03 (script and edit list) | script-writer, review-checklist |
| KM-003 | 2026-11-11 | Credits spent before a review | Start-frames (or a 20 s test) first; no batch motion until the pre-render checklist passes | review-checklist |
| KM-004 | 2026-11-11 | Generic "cinematic" direction | Style and camera must be numbers (hex, lens, push %/s, shot length), not adjectives alone | style-guide |
| KM-005 | 2026-11-11 | Subscribe line in a Short | No CTA on this channel | script-writer |
| KM-006 | 2026-11-11 | Indonesian VO judged "kurang Indonesia" twice (stock voice, then cloned voice) after full videos were built on it | New voice or engine: send a 10 s sample first and wait for the director's ear; transcription accuracy does not prove it sounds native | script-writer |
